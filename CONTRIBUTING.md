# Contributing to vstiff

Thank you for helping. Every rule for changing vstiff is in [AGENTS.md](AGENTS.md), and the rules
are the same for people and for coding agents: read it before your first change.

To propose a change, fork the repository, branch from `main` and open a pull request against it.
Questions and bug reports go in the [issue tracker](https://github.com/vjaganat90/vstiff/issues).

- [docs/README.md](docs/README.md) lists what to know before reading the code.
- [docs/onboarding.md](docs/onboarding.md) is a ten-day path from zero to a first contribution.
- [docs/exercises.md](docs/exercises.md) ends with starter contributions.
